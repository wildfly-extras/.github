# .github

This repository contains GitHub-specific files for the ['wildfly-extras' GitHub organization](https://github.com/wildfly):

* Its [profile page](https://github.com/wildfly-extras/.github/tree/main/profile#readme), providing the content shown on the [organization page](https://github.com/wildfly).
* [Default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for repositories in the organization.

Note that the .gitignore, dco.txt, LICENSE and SECURITY.md files in this repository are not default community health files; their presence here does not remove the need for equivalent files in other repositories in the organization.
